Can I download Mirra?

Not as a finished app yet. The source is on GitHub: you run the web app, or build the desktop app for macOS, Windows or Linux.

Do I need Taobao API keys?

For live Taobao results, yes: an affiliate account, an app key and an adzone id. Without them Mirra shows a clearly marked sample catalog.

Does Mirra sell replicas?

Mirra sells nothing. It labels listings that advertise as replicas and never sends them to KakoBuy.

Is the 3D try-on exact?

No. It shows a garment of the same type, colour and fit on your avatar, labelled approximate.

Are my photos kept?

No. A photo goes to Claude only when the server has an Anthropic key, and Mirra stores none.

Run Mirra on your own machine

Web and desktop from one codebase. Taobao and eBay keys are optional.
